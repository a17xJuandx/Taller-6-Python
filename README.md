# Programación de Computadores en Python
## Taller 6: Funciones y Modularización
#### Universidad Nacional de Colombia[cite: 2]

---

Este repositorio contiene la solución a los ejercicios del **Taller 6**, enfocados en la implementación de funciones, el uso de funciones anidadas, la documentación de código mediante Docstrings y la aplicación de librerías estándar de Python para la resolución de problemas técnicos[cite: 2].

---

## Descripción de los Ejercicios

* **a) Generador alfabético:** Implementación de una función que imprime una secuencia de letras del abecedario según la cantidad especificada por el usuario[cite: 2].
* **b) Distancia euclidiana en 3D:** Función para calcular la distancia geométrica entre dos puntos definidos por coordenadas $(x, y, z)$ en un espacio tridimensional[cite: 2].
* **c) Calculadora de fracciones:** Módulo funcional para la suma de fracciones. Incluye validación de denominadores, simplificación mediante el máximo común divisor (MCD) y gestión de tuplas para representar números racionales[cite: 2].
* **d) Alcance de proyectiles (Cañón de agua):** Función `alcance_chorro` que calcula el desplazamiento horizontal de un fluido bajo condiciones de gravedad constante ($9.81 \, m/s^2$), considerando velocidad inicial, ángulo de disparo y altura relativa[cite: 2].
* **e) Cálculo de volumen cilíndrico:** Implementación de una función principal con una **función anidada** para el cálculo del área de la base, orientada a determinar el volumen total de un tanque cilíndrico con alta precisión[cite: 2].

## Especificaciones Técnicas

* **Documentación:** Cada función incluye *Docstrings* descriptivos detallando parámetros de entrada y valores de retorno[cite: 2].
* **Librerías:** Uso de la librería `math` para operaciones trigonométricas y cálculos matemáticos complejos[cite: 2].
* **Entorno de ejecución:** Desarrollado y optimizado para entornos de Google Colab[cite: 2].
